# VPN IR

پروژه یکپارچه فروش و مدیریت خدمات VPN IR شامل وب‌سایت، ربات تلگرام و پنل مدیریت.

## ساختار پروژه

- `web/`: وب‌سایت مشتریان
- `bot/`: ربات تلگرام و گردش‌کار سفارش‌ها
- `supabase/`: ساختار دیتابیس، سیاست‌های دسترسی و توابع سمت سرور
- `docs/`: راهنمای نصب، استقرار و مدیریت

## امنیت

اطلاعات محرمانه فقط در متغیرهای محیطی سرویس میزبان ثبت می‌شوند. فایل واقعی `.env`، توکن ربات تلگرام و کلید Supabase Service Role نباید در Git ثبت شوند.

## وضعیت

مخزن برای پیاده‌سازی نسخه یکپارچه VPN IR آماده شده است. قابلیت‌ها پس از پیاده‌سازی و آزمون مستند خواهند شد.
